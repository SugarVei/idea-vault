# 重拳飞车 · 盐炉高台

双击 `index.html` 即可在支持 WebGL 的浏览器里离线游玩。首页的「快速开赛」会直接进入盐炉高台的三回合相扑。自定义比赛可以更换场地、赛制、对手和车辆。原有五种玩法都可从首页进入。

| 操作 | 按键 |
| --- | --- |
| 加速、倒车、转向 | W / S / A / D |
| 漂移并积攒氮气 | Shift + 转向 |
| 释放氮气 | 空格 |
| 出拳 | 鼠标左键点按，按住可蓄力，J 也可出拳 |
| 使用道具 | 鼠标右键或 Q，熔毁模式中用于氮气小跳 |
| 暂停 | Esc |

相扑拾取的强化拳和涡轮加速会存入一个道具位，使用后持续 7 秒。双人模式的第二名车手仍用方向键及独立的动作键。触屏操作在比赛中提供虚拟摇杆和独立动作按钮。

## 模型和修改

- `foundry.js` 定义盐炉高台的场地材质、碰撞布置和场景道具。`models/saltworks-arena.glb` 是首回合的静态模型，缩圈、灯光和碰撞由游戏运行时配置。
- `saltworks-vehicles.js` 定义疾风、悍将和重锤的车壳及车轮。`models/saltworks-vehicles/` 提供三款独立 GLB，游戏使用原有的涂装与动态特效系统。
- `saltworks-ui.css` 和 `match-mouse.js` 分别包含界面样式和鼠标输入。改完后从此目录运行 `python -B rebuild.py`，把修改打包回单文件 `index.html`。脚本读取已有 Git 历史中的固定上游版本，也可用 `--baseline` 指定原版 HTML。
